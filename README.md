# ARC — AI Knowledge Workspace

ARC is a local-first notes workspace designed to help ideas connect.

## Product scope
- Responsive web workspace with dark and light themes
- Notes, folders, tags, search, favorites and backlinks
- Markdown editing and autosave
- Three-dimensional knowledge graph
- Gemini-powered summarization and note Q&A
- Offline-first storage and cross-device synchronization
- Android and iOS Flutter application

## Security
Gemini API keys must stay on the server. Never expose them in frontend code or commit `.env` files.

## Status
The repository is being initialized. Features will be marked complete only after implementation and verification; this README is a roadmap, not a claim that every feature is already shipped.
